Background services this script turns off

Telemetry. DiagTrack is the Connected User Experiences and Telemetry service — the client that packages and sends Windows diagnostic data. Disabling it and setting AllowTelemetry to 0 reduces what leaves the machine, but it doesn't eliminate data collection outright: Microsoft's own documentation describes multiple telemetry levels and collection paths, so treat this as a meaningful reduction, not a guarantee of zero data leaving the device.

Cortana / search policy. AllowCortana set to 0 turns off Cortana's search integration at the policy level.

Xbox services. XblGameSave, XboxNetApiSvc and XboxGipSvc handle Xbox Live save sync and controller/accessory pairing. If any games you play use Xbox cloud saves (common with Game Pass and Play Anywhere titles), disabling these stops that sync — worth checking before you run this if you rely on cross-device saves.

OneDrive: full removal, not a toggle

This isn't a setting flip — the script kills the OneDrive process and runs its own uninstaller, then blocks silent reinstallation via policy. Anyone using OneDrive for automatic document backup, screenshot sync, or Office autosave-to-cloud will lose that the moment this runs. It's reversible (re-run OneDriveSetup.exe manually, or reinstall from Microsoft), but it's a real removal, not a background toggle you can flip back with a registry edit alone.

Power, network and visual settings

The script activates Windows' built-in High Performance power plan — maximum CPU clocks, minimal throttling. On a desktop that's plugged in permanently, that's close to a pure upside. On a laptop, it means faster battery drain and more fan noise even at idle; this plan was written with a desktop in mind.

NetworkThrottlingIndex and SystemResponsiveness control a Windows multimedia feature (MMCSS) originally built to reserve a slice of network capacity so background traffic wouldn't cause audio or video stutter. Setting the throttling index to its maximum value and responsiveness to 0 removes that reservation entirely. It doesn't add bandwidth — it just stops Windows from holding a slice back for itself.

Visual effects are switched to a performance-oriented set via individual UserPreferencesMask and related values — disabling animations, transparency, and menu delay one setting at a time rather than through the single "Adjust for best performance" switch.

A GENUINELY GOOD CHANGE Disabling SMB1 (step in the file system section) isn't just a performance tweak — SMB1 is an old, known-vulnerable protocol version (it was the vector used by WannaCry). Turning it off is a real security improvement almost every modern machine benefits from, with essentially no downside unless you have very old network hardware that specifically requires it.

Delivery Optimization (P2P updates)

Windows can share update files peer-to-peer, both with PCs on your own network and, depending on settings, over the internet with other Windows machines. Setting DODownloadMode to 0 and disabling the DoSvc service turns that off: your machine pulls updates directly and only from Microsoft, and stops uploading pieces of updates to anyone else in the background.

FAQ

Can I get OneDrive back after running this?

Yes — download and run OneDriveSetup.exe again, or reinstall from Microsoft's site. It won't reappear on its own because of the policy block this script sets.

Does disabling telemetry stop all data collection?

No. It reduces the diagnostic data DiagTrack sends, but Microsoft collects some data through other mechanisms regardless of this setting. Treat it as a reduction, not a full opt-out.

Is this reversible?

Mostly. Re-enabling the disabled services and flipping the registry values back to their Windows defaults restores most of this. OneDrive specifically needs a manual reinstall.
