WHY A GUIDE, NOT JUST A FILE

Read before you run it as Administrator

Every one of these scripts asks for elevated rights and changes real system state — services, registry keys, boot configuration. A download link with no explanation asks you to trust a stranger's judgment about your own machine. These guides exist so you don't have to: each setting is traced back to what it actually does, including the couple of places where the honest answer is "this is riskier than it looks" or "this line doesn't do what it seems to."
